nmap + ssl/tls recon, one command

Find the open port.

what it does

Recon and TLS inspection, without switching tools

Point it at a target, get back the ports, the certificates, and the weak spots — in one pass.

01 · discovery

Port & service scan

Runs Nmap under the hood to find open ports and identify which ones are serving SSL/TLS.

02 · certificates

Certificate inspection

Pulls issuer, subject, validity window, and expiry so you can spot stale or misissued certs fast.

03 · protocols

Protocol & cipher check

Lists supported TLS versions and cipher suites, flagging outdated or weak configurations.

04 · triage

Color-coded findings

Terminal output separates informational results from actual warnings, so nothing gets buried.

05 · reporting

Exportable results

Save scans as JSON or plain text to drop straight into a report or a follow-up ticket.

06 · scope

Single host or range

Works against one host and port, or a defined range, from the same command.

setup

Installation

Needs Python 3.8+, Nmap on your PATH, and OpenSSL.

1

Clone the repository

# git clone https://github.com/atiksharier7-hosst92/NmapSSL.git
cd NmapSSL
2

Install dependencies

# pip install -r requirements.txt
3

Confirm Nmap is available

# nmap --version

running a scan

Usage

Point it at a target and a port, or leave the port off to default to 443.

# python nmapssl.py -t example.com -p 443
FlagDescription
-t, --targetTarget IP address or domain
-p, --portPort or port range to scan (default: 443)
-o, --outputSave results to a file
-v, --verboseShow detailed scan output

Use responsibly. NmapSSL is built for education and authorized security testing. Only scan systems you own or have explicit permission to test.
